Правило

Каждый день после закрытия: акции NASDAQ с close > SMA200, день ≤ −3%, оборот ≥ 20M$/д, цена ≥ 5$ → 2 самых ликвидных = пики дня. Тир по QQQ RSI(2): A < 10 и B 10–30 — торгуем: купить по открытию следующей сессии, продать по закрытию сессии после дня входа, 10% капитала на имя, без стопов и целей. C ≥ 30 — только наблюдаем.
Серии из 5–7 убыточных подряд — норма; судить раньше 40–50 сделок нельзя. Подробности — STRATEGY.md.
