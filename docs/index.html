Правило v2

Когда: QQQ RSI(2) по закрытию < 10. Что: акции NASDAQ с close > SMA200, день ≤ −3%, оборот ≥ 20M$/д → самые ликвидные, не больше 2 новых в день, до 4 позиций по 25% капитала. Вход: следующее открытие. Выход: открытие после первого закрытия выше SMA10 акции, максимум 20 сессий. Без стопов и целей.
Почему так: в v1 выход был жёстко через 48 ч и рубил отскок на середине (+81 б.п./сделку, 58% прибыльных). Выход по SMA10 даёт отскоку доиграть: +181 б.п., 70%. Проверено на 2010–2016 (эти годы не участвовали в подборе выхода): CAGR 20%, 7 из 7 лет в плюсе. Подробности и весь перебор — STRATEGY.md.
