# EOD Pre-Move Scanner — NASDAQ

Сканер акций NASDAQ: **сигнал в 15:30 ET (за 30 минут до закрытия) по неполной свече → вход по цене закрытия → цель +2…+5% за 24–48 часов** (включая положительный гэп следующего дня).

Главный слой сканера — **pre-move («перед движением»)**: акции в аптренде, которые находятся в пределах 15% от максимума 52 недель, сегодня тихие (<3%) и без резких всплесков за неделю (<4%) — то есть движение ещё **не началось**, вход до его начала, а не после. Второй слой (momentum) — те, кто уже начал двигаться, показан для сравнения.

> ⚠️ Никакой алгоритм не может *гарантировать* рост акции. Система оценивает **вероятность** движения на исторических данных
> (бэктест вне выборки окт 2025 – авг 2026: pre-move слой ~37% попаданий против ~31% у рынка, худшее 2-дневное движение ~−0.6%;
> momentum слой ~48% попаданий при худшем ~−1.3%).
> Это исследовательский инструмент, а не индивидуальная инвестиционная рекомендация. Стоп −3% и позиция 1–2% капитала обязательны.

## Как это работает

1. **15:30 ET** — сканер строит неполную свечу текущего дня из 30-минутных баров (до 15:30; объём неполной свечи масштабируется на полный день, чтобы vol_ratio был сопоставим с обучением) и считает скор по ~200 ликвидным акциям.
2. **15:55–16:00 ET** — вход по цене закрытия.
3. **24–48 часов** — выход на целях +2%/+5% (или стоп −3%).
4. Статистика гэпа следующего дня (вне выборки) показывается по каждому тикеру.
5. Калибровка вероятностей — по **вне-выборочным** (OOS) предсказаниям walk-forward бэктеста, а не на обучающих данных.

## Автоматизация (GitHub Actions + Pages)

- Workflow `.github/workflows/daily_scan.yml` запускается **автоматически в будни в 15:30 ET** и по кнопке (**Actions → Run workflow**).
- Данные кэшируются на раннере (месячный кэш) — ежедневный прогон ~3–5 минут.
- Результаты коммитятся в репозиторий, дашборд публикуется на **GitHub Pages**:
  `https://<логин>.github.io/nasdaq-eod-momentum-scanner/`
- Для Pages нужна одноразовая настройка: **Settings → Pages → Source: GitHub Actions**.

## Результаты бэктеста (окт 2025 – авг 2026, вне выборки, walk-forward)

Два слоя, оба ранжируются вероятностью модели (36 признаков = 24 базовых + 12 «койл»):

| Слой | Попадание +2%/48ч | Средн. лучшее | Худшее за 48ч | Кандидатов/день |
|---|---|---|---|---|
| **pre-move** (аптренд + у максимумов + тихий день + без всплеска) | **~37%** (рынок ~31%) | +1.5% | **~−0.6%** | ~5 |
| momentum (топ-10% по скору, все имена) | ~48% | +2.5% | ~−1.3% | ~27 |

- **Точка pre-move**: вход ДО начала движения — худшее 2-дневное движение вдвое меньше, чем у «уже движущихся», а попадание выше базы. Pre-move слой опережал базу рынка в **10 из 11** вне-выборочных месяцев.
- Momentum-слой даёт больше попаданий, но входит после начала движения (выше риск отката) — оставлен для сравнения.
- Чистый «койл» без тренда/максимумов **не является** альфой (по данным бэктеста сжатие волатильности само по себе даёт *ниже* среднюю доходность), поэтому это структурный фильтр «где может начаться движение», а не сам сигнал — ранжирует вероятность модели.

## Валидация сигнала в 15:30 (неполная свеча)

125 торговых дней × 60 ликвидных акций:
- Корреляция скоров 15:30 vs закрытие: **0,98**
- Пересечение топ-10: **8,4 из 10**
- Хит-рейт ≥2% по сигналу 15:30: **54%** (по закрытию 56%) — потеря всего ~2 п.п.

## О гэпе следующего дня

Статистика вне выборки: после сигналов модели вероятность положительного гэпа на следующее утро — **50–60%** (у лидеров скана), медианный гэп около нуля или слегка положительный. Гэп — это бонус; основной заработок — движение к целям +2/+5% в течение 24–48ч. **Не рекомендуется выходить по открытию** — после распродажных дней гэп часто негативный, а отскок идёт внутри дня.

## Ограничения

- Вероятности ухудшаются при смене рыночного режима (кризис, распродажа AI-сектора).
- Даже в pre-move слое ~2 из 3 сделок не достигают цели +2% — управление риском обязательно.
- «Тихий день» в 15:30 — это состояние до закрытия; если в последние 30 минут идёт всплеск, свеча и фильтр могут не отразить финальный импульс.
- Данные: Nasdaq.com screener, Yahoo Finance.

## Вселенная (юниверс) — как она живёт

- **Состав:** все акции биржи NASDAQ с ценой ≥ $3 и капитализацией ≥ $500 млн (сейчас ~1500). Список берётся с официального скринера Nasdaq.com **при каждом прогоне** (`src/update_universe.py`).
- **Она меняется, но не уменьшается:** новые IPO добавляются, делистинги/банкротства удаляются, акции переходят границы цены/капитализации. Обычно 1400–1600 имён. Никакого «схлопывания» нет — обновляется автоматически.
- Из вселенной для скана отбирается **топ-200 по ликвидности** (оборот ≥ $5 млн/день), поэтому сканер всегда работает с торгуемыми акциями.
- Для новых имён история докачивается автоматически (полная 2-летняя), для старых — только инкрементально (быстро).

## Ручной запуск

Три способа:
1. **Кнопка на дашборде** («▶ Запустить скан сейчас») — если настроен секрет `SCAN_TRIGGER_TOKEN` (см. ниже). Триггерит workflow через `repository_dispatch`.
2. **Вкладка Actions** — открой `Actions → EOD Scanner (15:30 ET) → Run workflow`.
3. **Автоматически** — будни в 15:30 ET.

### Настройка кнопки на дашборде (одноразово) — заодно включает Pages автоматически
1. Создай **fine-grained PAT** (`github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token`):
   - **Token name:** `scan-trigger`
   - **Repository access:** Only select repositories → `nasdaq-eod-momentum-scanner`
   - **Permissions:** `Actions: Read and write` **и** `Pages: Read and write` (только эти два!)
2. Добавь его как секрет: `Settings → Secrets and variables → Actions → New repository secret`, имя `SCAN_TRIGGER_TOKEN`.
3. Запусти workflow (вкладка Actions → Run workflow) — GitHub Pages включится **сам**, дашборд соберётся с активной кнопкой.
4. Кнопка на дашборде вызывает `workflow_dispatch` через API — токену нужно только `Actions: write`, поэтому его безопасно встраивать в публичный HTML (он не может трогать код и данные).
   Если кнопка не нужна — не настраивай секрет; кнопка будет вести на вкладку Actions, а Pages включи вручную.
