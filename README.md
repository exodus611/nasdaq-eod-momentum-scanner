# EOD Momentum Scanner — NASDAQ

Сканер акций NASDAQ с покупкой на закрытии торгового дня и целью **+2…+5% за 24–48 часов**.

> ⚠️ **Важно:** ни один алгоритм не может *гарантировать* рост акции. Система оценивает **вероятность** движения
> на исторических данных (бэктест вне выборки: ~49% попаданий против ~34% у среднего по рынку). Это исследовательский
> инструмент, а не индивидуальная инвестиционная рекомендация. Обязательный стоп-лосс и ограничение размера позиции.

## Что внутри

| Файл | Назначение |
|---|---|
| `output/dashboard.html` | **Готовый дашборд** — фавориты недели, уровни входа/цели/стопа, сценарии, графики, результаты бэктеста. Открывается в любом браузере без интернета |
| `output/scan_results.csv` | Полный рейтинг 60 кандидатов последнего скана |
| `src/features.py` | Инжиниринг 24 признаков (моментум, свечи, RSI, тренд, волатильность, объём, ликвидность) |
| `src/backtest.py` | Walk-forward бэктест (обучение на прошлом → тест на следующем месяце) |
| `src/scan.py` | Живой скан: реконструкция пятничной свечи из внутридневных баров + скор модели |
| `src/build_dashboard.py` | Генерация `dashboard.html` |
| `src/download_history.py` | Загрузка 2-летней истории по юниверсу (Nasdaq screener + Yahoo Finance) |

## Как запустить

```bash
pip install yfinance pandas numpy scikit-learn pyarrow
python src/download_history.py     # 1) история (однократно, ~10 мин)
python src/backtest.py             # 2) бэктест стратегии
python src/scan.py                 # 3) сканер на сегодняшний день
python src/build_dashboard.py      # 4) собрать дашборд
```

Обновление сигнала: после закрытия рынка (например, в пятницу вечером) прогнать шаги 3–4.

## Методология

1. **Юниверс** — 1500+ ликвидных акций NASDAQ (цена ≥ $5, оборот ≥ $5 млн/день).
2. **Признаки на конец дня** (24 шт.): моментум 1/2/3/5/10/21 день, позиция закрытия в дневном диапазоне, тени/тело свечи, гэпы, RSI(14), положение к SMA50/SMA200, тренд EMA20/50, ATR/ADR (волатильность), объём vs 20-дневный, расстояние до 52-недельных экстремумов, серии дней, ликвидность.
3. **Модель** — градиентный бустинг (HistGradientBoosting), ~450 тыс. обучающих примеров за 2 года. Метка: «акция выросла ≥2% хотя бы в один из 2 следующих дней».
4. **Отбор** — топ по скору с фильтром ликвидности; для топ-60 пятничная свеча реконструируется из 60-минутных баров (закрытие, VWAP, позиция в диапазоне, последний час) и добавляется в признаки.
5. **Результат** — 1–2 фаворита с полным разбором (фундаментал, техническое состояние, 3 сценария, уровни) + рейтинг всех кандидатов.

## Результаты бэктеста (окт 2025 – авг 2026, вне выборки)

- Попадание «рост ≥2% за 48ч»: **48,8%** (база рынка 34,4%)
- Среднее лучшее движение за 48ч: **+2,9%** (база +1,4%)
- Средний результат 2-го дня: **+0,9%** (база +0,3%)
- Стратегия опережала базу во **все 11 месяцев**

## Ограничения

- Вероятности ухудшаются при смене рыночного режима (кризис, распродажа AI-сектора).
- Почти каждая вторая сделка не достигает цели +2% — управление риском обязательно (стоп −3%, позиция 1–2% капитала).
- Данные: Nasdaq.com screener, Yahoo Finance. Внутридневные бары последнего дня могут быть не финализированы — свеча реконструируется из 60-мин баров.
