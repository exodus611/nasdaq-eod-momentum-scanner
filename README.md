# Dip-Buyer NASDAQ 48h — paper trading

Раз в день после закрытия рынка США сканер проверяет одно условие и, если оно выполнено, выводит **две акции**: купить завтра по открытию, продать послезавтра по закрытию. Ордера не исполняются. Результат — на дашборде (GitHub Pages) и в блоке ниже; бумажный журнал сделок по реальным ценам открытия/закрытия ведётся в репозитории.

## Правило

Каждый день после закрытия сканер выдаёт **2 бумаги** и **тир рынка**. Что делать — зависит от тира.

| | |
|---|---|
| **Фильтр (каждый день)** | акции NASDAQ: цена выше SMA200, сегодня упали **≥ 3%**, средний оборот ≥ 20M$/день, цена ≥ 5$ → **2 самые ликвидные** |
| **Тир A** 🟢 | QQQ RSI(2) по закрытию **< 10** — рынок перепродан. **Торгуем.** ~2 дня в месяц |
| **Тир B** 🟡 | QQQ RSI(2) **10–30** — рынок слабый. **Торгуем.** ~3 дня в месяц |
| **Тир C** ⚪ | QQQ RSI(2) **≥ 30** — обычный день. **Не торгуем**, только наблюдаем (paper-журнал ведётся). Большинство дней |
| **Вход / выход** | завтра **по открытию** → послезавтра **по закрытию** (закрытие следующего дня после дня входа). Без стопов, без целей |
| **Размер** | 10% капитала на имя |

Почему так — в [STRATEGY.md](STRATEGY.md). Коротко: из ~40 сетапов, проверенных на 2010–2026, покупка ликвидных падений на 48 часов — единственный, который в плюсе после издержек, и **только в дни, когда падает весь рынок**. В обычные дни та же самая сделка убыточна. Поэтому пики есть каждый день, но покупать их предлагается только в тирах A и B.

|---|---|---|---|---|---|

| **B** 🟡 | RSI2 10–30 | 791 (~79/год) | **+24 б.п.** | 53% | 6/10 |

| каждый день без разбора | — | 4 416 | −11 б.п. | 49% | 4/10 |

Тир A на 2010–2026 (782 сделки): +57 б.п., 56% прибыльных, 14 из 17 лет в плюсе — все сделки в [results/trades_top2_2010_2026.csv](results/trades_top2_2010_2026.csv). Тир B — слабее и менее стабилен по годам (2021: −159 б.п. в среднем, 2018: +22, 2025: +130); он добавлен, чтобы сделок было ~10 в месяц, а не 4. Худшая сделка за 17 лет: −25%. Серии из 5–7 убыточных подряд — норма. **Вероятность, что любые 10 подряд сделок в сумме убыточны — ~40%.** Судить о стратегии можно не раньше 40–50 сделок (≈ 4–5 месяцев при A+B).

## Установка

Уже развёрнуто в этом репозитории. Дашборд: **https://exodus611.github.io/nasdaq-eod-momentum-scanner/** (публикуется самим workflow через GitHub Pages).

1. Ручной запуск: **Actions → «Dip-Buyer daily scan» → Run workflow** (mode `run`). Через 2–3 минуты появится коммит `scan: …`, обновится блок выше и дашборд.
2. Если workflow не может пушить: **Settings → Actions → General → Workflow permissions → «Read and write permissions»** → Save.
3. Необязательно: Settings → Secrets and variables → Actions → Variables: `CAPITAL` (100000), `PER_NAME` (0.10), `TOP_N` (2), `TIER_A` (10), `TIER_B` (30), `PAGES_URL` (ссылка на дашборд для блока в README).

Дальше всё само: каждый торговый день в ~16:40 ET (23:40 по Израилю летом, 22:40 зимой; GitHub может задержать запуск на 5–30 минут — не страшно, вход всё равно завтра по открытию) — скан, коммит журнала, обновление дашборда.

## Что показывает дашборд

- **Статус дня:** QQQ, RSI(2), тир A/B/C, шкала RSI.
- **Действия на следующую сессию:** 2 бумаги — КУПИТЬ по открытию (тир A/B: тикер, сумма, ~штук) или НАБЛЮДЕНИЕ (тир C); что продать по закрытию.
- **Вывод сканера:** все акции, прошедшие фильтр в этот день, по обороту.
- **Результаты по тирам:** P&L стратегии (A+B) отдельно от наблюдения (C) и от «если бы торговали каждый день» — видно, работает ли фильтр по рынку на живых данных.
- **Открытые позиции, сделки, equity, журнал сканирований.**

Каждый скан также сохраняется в `state/scans/<дата>.json`, журнал сделок — `state/journal.csv`, лог запусков — `state/daily_log.csv`.

## Файлы

- `bot.py` — сканер + бумажный журнал + дашборд. `python bot.py run --asof 2026-08-20` — прогон на историческую дату; `python bot.py backfill --from 2026-08-10 --to 2026-09-09` — реплей диапазона одной загрузкой (помечается `replay`).
- `research/daily_tiers.py` — тест тиров на 10 годах (таблица выше).
- `scan_once.py` — тот же сигнал одной командой, без журнала.
- `.github/workflows/daily.yml` — ежедневный запуск после закрытия (+ публикация дашборда в Pages).
- Прежний сканер (momentum/pre-move, 10 бумаг) сохранён целиком в ветке [`legacy-scanner`](../../tree/legacy-scanner); разбор его слабых мест — в `STRATEGY.md`.
- `results/` — бэктест 2010–2026 (топ-10 и топ-2), `research/` — весь код исследования, `research/PLAN.md` — протокол (написан до OOS-прогона).

## Честные оговорки

- Данные — Yahoo Finance через `yfinance`, бесплатно и без гарантий. Если бар за день не пришёл — бот скажет об этом на дашборде и ничего не сделает; можно перезапустить вручную (Run workflow → `run`).
- Бэктест на сегодняшнем составе NASDAQ (без делистингованных). Для 2 самых ликвидных имён (TSLA, NVDA, AAPL, AMZN, AMD, META чаще всего) эффект мал, но реальный результат может быть на 10–20 б.п./сделку хуже.
- Стратегия покупает падающие акции в дни распродаж. Она **должна** периодически выглядеть глупо — иначе бы не платила.
